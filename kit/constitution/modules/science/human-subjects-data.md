## B.S-DATA: Human-subjects and sensitive data

*Module: human-subjects-data v0.1 (**draft, untested**). Select this whenever the project touches data about real people.*

1. **Real data never enter the repository.** That includes fixtures, examples, plans, reports and
   history. Tests use synthetic data generated by a committed script.
2. **Data live at {{DATA_LOCATION}}.** Agents may read them only where the PI's ruling permits, and
   never paste them into tools or services outside the project.
3. **Pseudonymize at the boundary.** Outputs cite IDs, never names. Re-identification keys are kept
   outside the project.
4. **The ethics approval {{IRB_REFERENCE}} governs** what is collected, kept and shared. Any change
   to collection, retention or sharing is Tier C, and may need an amendment to the approval.
5. **Reproducibility without exposure.** Every analysis that runs on real data also runs on a
   synthetic dataset with the same structure, so reviewers and other researchers can reproduce the
   pipeline.
