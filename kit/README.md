# The ARPD kit library

This folder is the ARPD kit's library: the charter template and modules (`constitution/`), the
governing-document and report templates (`templates/`), the agent roles (`agents/`), the tools
(`tools/`), the hook settings (`settings/`) and the event-log description (`docs/`). The setup skill
copies from here into a project. It travels with every installed project, so this note does too.
